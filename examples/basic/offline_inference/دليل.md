# دليل

هذا الدليل بالعربية لوكيل vLLM يعيد إنتاج رد ثابت، ثم يبني ناتجاً أصلياً في البناء والفيديو والصوت والصور. معه أداة مفتاح محلية ومهارة للوكيل.

## الأدوات

- إعادة الإنتاج والبناء الأصلي: `python examples/basic/offline_inference/dalil.py --task all`
- مفتاح الواجهة، يُطبع مرة واحدة ولا يُحفظ في المستودع: `python examples/basic/offline_inference/generate_secret_key.py`
- كتابة المفتاح خارج المستودع بصلاحية `0600`: `python examples/basic/offline_inference/generate_secret_key.py --out /tmp/vllm-api-key`

مرّر المفتاح إلى الخادم عبر `VLLM_API_KEY` أو `--api-key` فقط. لا ترسله إلى أي مضيف آخر.

## النماذج

| المهمة | النموذج | متى |
| --- | --- | --- |
| نص عربي على هذا الجهاز | `Qwen/Qwen2.5-0.5B-Instruct` | الافتراضي. لا توجد وحدة رسوم. |
| فهم صورة أو فيديو | `Qwen/Qwen2.5-VL-7B-Instruct` | وصفة معالج موثقة. يحتاج ذاكرة أكبر من النموذج النصي. |
| صوت | نموذج تقبل بطاقته `audio_url` | لا ترفق صوتاً بالنموذج النصي الافتراضي. |

أجزاء الوسائط في الدردشة هي `image_url` و`audio_url` و`video_url`. النموذج النصي يكتب الخطة. هو لا يرسم صورة ولا يركّب فيديو ولا يولّد ملفاً صوتياً.

## إعادة إنتاج البيئة

على جهاز بلا وحدة رسوم، ابنِ امتدادات المعالج من المصدر. اجعل المترجم GCC، لأن `/usr/bin/c++` قد يكون Clang بلا مكتبة `libstdc++` المطابقة.

```bash
uv venv --python 3.12 --seed --managed-python
source .venv/bin/activate
uv pip install -r requirements/build/cpu.txt --torch-backend cpu --index-strategy unsafe-best-match
uv pip install -r requirements/cpu.txt --torch-backend cpu --index-strategy unsafe-best-match
export CC=/usr/bin/gcc
export CXX=/usr/bin/g++
export MAX_JOBS=2
export VLLM_TARGET_DEVICE=cpu
uv pip install --editable . --no-build-isolation --torch-backend cpu --index-strategy unsafe-best-match
```

ثم:

```bash
export VLLM_CPU_OMP_THREADS_BIND=nobind
export VLLM_CPU_KVCACHE_SPACE=1
python examples/basic/offline_inference/dalil.py --task all
```

قسم «إعادة الإنتاج» يثبت أن الطلب نفسه يعيد نصاً عربياً. قسم «البناء الأصلي» يطلب أربعة أسطر جديدة عن حديقة في الرياض: البناء، والفيديو، والصوت، والصور.

## إرفاق وسيط

```bash
python examples/basic/offline_inference/dalil.py \
  --model Qwen/Qwen2.5-VL-7B-Instruct \
  --image-url https://vllm-public-assets.s3.us-west-2.amazonaws.com/multimodal_asset/cat_snow.jpg \
  --task construct
```

`--audio-url` و`--video-url` يعملان بالطريقة نفسها عندما يقبل النموذج تلك الوسيلة.

## المهارة

مهارة الوكيل اسمها `dalil` ونصها هذا الدليل. استخدمها عندما يطلب العمل إعادة إنتاج رد عربي، أو بناء خطة للبناء والفيديو والصوت والصور، أو توليد مفتاح محلي.
