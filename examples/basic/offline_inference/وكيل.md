# الوكيل الكامل

هذا الوكيل يبتلع ملف JSONL إلى بيان تدريب، ثم يعيد إنتاج رد عربي ويبني خطة للبناء والفيديو والصوت والصور. المفتاح المحلي أداة منفصلة ولا يُكتب داخل المستودع.

## الأوامر

```bash
python examples/basic/offline_inference/wakil.py \
  --task ingest --input corpus.jsonl --dedupe

python examples/basic/offline_inference/wakil.py \
  --task all --input corpus.jsonl

python examples/basic/offline_inference/wakil.py \
  --task key --out /tmp/vllm-api-key
```

`--task all` من غير `--input` يتخطى الاستيعاب ويشغّل النموذج فقط. وسيطات النموذج التي لا يعرفها هذا الأمر، مثل `--model` و`--max-tokens`، تُمرَّر إلى `dalil.py`.

مرّر المفتاح عبر `VLLM_API_KEY` أو `--api-key` فقط. لا تحفظه في المستودع ولا ترسله إلى مضيف آخر. ملف البيان يبقى على جهازك.

## ماذا يُحفظ من كل سطر

السطر الفارغ يُهمل. السطر الذي ليس JSON يُحسب ويُتجاوز، ومع `--strict` تتوقف الكتابة ويبقى المخرج السابق كما هو. السجل الذي لا يحوي نصاً يُتجاوز.

| الشكل | النص الناتج |
| --- | --- |
| `text` أو `content` | النص نفسه. القائمة تُقرأ من أجزاء `text` فقط |
| `messages` أو `conversations` | سطر لكل دور: `role: text` |
| `instruction` و`input` و`output` | الأجزاء غير الفارغة يفصلها سطر فارغ |
| `prompt` و`completion` أو `question` و`answer` | بالطريقة نفسها |
| من غير `source` | `unknown`. يُقبل `dataset` مكانه |

`text` يسبق بقية الحقول في السجل نفسه. `--dedupe` يسقط النص المكرر بعد حذف الفراغ الطرفي. `--keep-meta` يلحق `id` و`lang` و`split` فقط. `--min-chars` و`--max-chars` يحدّان الطول، والصفر في الأعلى يعني بلا حد.

المخرج الافتراضي `data/training-manifest.jsonl`. كل سطر فيه `text` و`source`. الطباعة JSON وفيها `written` و`output` والعدّادات.

## النموذج

تفاصيل إعادة الإنتاج والبناء والوسائط في [دليل.md](دليل.md). على المعالج قبل التحميل:

```bash
export VLLM_CPU_OMP_THREADS_BIND=nobind
export VLLM_CPU_KVCACHE_SPACE=1
```

## المهارة

مهارة الوكيل اسمها `wakil`. استخدمها عندما يطلب العمل استيعاب JSONL، أو تشغيل الوكيل الكامل، أو توليد المفتاح المحلي.

## كل الوكلاء

فهرس الخمسة والثلاثين ورسومات الاستيراد في [agents/README.md](agents/README.md). أمرها `studio.py` منفصل عن `--task all`: هذا الأمر يبقى استيعاباً ثم نموذجاً، والاستوديو يبني الصفحة والخطة ومسودة العقد والقيد والدفتر وخطة الفيديو وبطاقة النشر على الجهاز. لا يفتح اتصالاً ولا ينشر. النص العربي المحلي، إن وُجد الملف، يذهب إلى خادم llamafile على `127.0.0.1:8080` فقط.
